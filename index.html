DICOM metadata

——
IMAGO LITE · Learning Corner
Purpose: IMAGO Lite is for introductory quantitative DICOM inspection, ROI statistics, and simple contrast/noise measurements.

Pan and zoom

Pan changes which part of the image is visible. Zoom changes display magnification only; it does not alter image resolution or pixel size.

Window width and level

Window width controls the displayed range of values; window level controls its centre. In CT these are normally expressed in HU.

Pixel value and HU

Output value = Stored Pixel Value × Rescale Slope + Rescale Intercept

For conventional CT images, this transformed value is normally HU. For other modalities it is reported as a rescaled pixel value unless a quantitative unit is defined by the image.

ROI statistics

The ROI panel reports mean, sample SD, minimum, maximum, pixel count and area. SD in a homogeneous region is a simple noise estimate, but it does not describe noise texture.

SNR

SNR = |μsignal| / σsignal

This simple ROI definition is useful educationally but is not universal, particularly for CT.

CNR

CNR = |μsignal − μbackground| / σbackground

CNR expresses object-background separation relative to background noise.

SDNR

SDNR = |μsignal − μbackground| / √(σ²signal + σ²background)

This implementation includes noise from both ROIs. Always report the exact formula used.

Good practice

  • Verify modality, pixel spacing and rescale parameters.
  • Use sufficiently large homogeneous ROIs for noise.
  • Avoid edges when estimating background noise.
  • Keep ROI size and placement consistent across comparisons.
  • For frequency-dependent analysis, continue to full OPTIMVS IMAGO for MTF, NPS, TTF and d′.
